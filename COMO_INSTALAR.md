# PintaKids — como usar no PC e instalar no tablet

## 1. Usar no computador (agora mesmo)

Dê dois cliques em **`index.html`** dentro da pasta `C:\Claude Code - PintaKids`.
Ele abre no navegador e já funciona (desenhar, pintar, pontos, galeria).
Use o Chrome ou o Edge.

> No PC o mouse não tem "força", então a grossura do traço vem da **velocidade**:
> devagar = traço grosso, rápido = traço fino. Uma mesa digitalizadora (caneta)
> usa a pressão de verdade.

## 2. Colocar no tablet (Android)

O app é um **aplicativo web instalável** (PWA). Para o tablet conseguir
instalá-lo ele precisa estar num endereço da internet com `https://`.
Depois de instalado, ele ganha **ícone próprio, abre em tela cheia e funciona
sem internet**.

Há dois caminhos. Os dois são gratuitos.

### Caminho A — GitHub Pages (recomendado: permanente)

1. Crie uma conta grátis em https://github.com
2. Crie um repositório novo chamado `pintakids` (público).
3. Envie todos os arquivos desta pasta para ele
   (o Claude pode fazer este passo por você).
4. No repositório: **Settings → Pages → Branch: main → Save**.
5. Em 1–2 minutos o app fica no ar em
   `https://SEU-USUARIO.github.io/pintakids/`

### Caminho B — Netlify Drop (mais rápido para testar)

1. Abra https://app.netlify.com/drop e crie uma conta grátis.
2. Arraste a pasta `C:\Claude Code - PintaKids` para a página.
3. Ele mostra um endereço `https://algo.netlify.app`.

### Instalando no tablet (vale para os dois caminhos)

1. No tablet, abra o endereço no **Chrome**.
2. Toque no menu **⋮** (canto superior direito) → **Instalar app**
   (ou **Adicionar à tela inicial**).
3. Pronto: o ícone do **Pingo** (a gotinha roxa) aparece na tela do tablet.

> A galeria, os pontos e os prêmios ficam guardados **no próprio tablet**.
> Não desinstale o app nem limpe os dados do Chrome, senão o progresso some.
> Para guardar uma pintura para sempre, abra-a na galeria e toque em
> **Enviar / salvar no aparelho**.

## 3. Área dos pais

Na tela inicial, toque na **engrenagem** (canto superior direito) e responda a
continha de multiplicação. Lá você pode:

- mudar o nome da criança;
- ligar/desligar sons e a voz que fala o nome das cores;
- ajustar a **sensibilidade do toque**;
- **liberar tudo** sem precisar de pontos;
- **adicionar desenhos próprios**: fotografe ou baixe qualquer página de
  colorir (Homem-Aranha, Patrulha Canina, Frozen…) e ela vira um desenho
  pintável, com balde e pintura mágica. Funciona melhor com linhas pretas em
  fundo branco.

## 4. Atualizar o app depois de uma mudança

Se o Claude mudar alguma coisa no app, é só enviar os arquivos de novo para o
mesmo lugar (GitHub ou Netlify). O tablet pega a versão nova na próxima vez que
abrir o app com internet. Os pontos e a galeria **não** se perdem.
